Portfólio pessoal desenvolvido para apresentar minha trajetória, conhecimentos e principais projetos na área de desenvolvimento de software.

Atualmente sou estudante de Análise e Desenvolvimento de Sistemas e estou em processo de transição de carreira para a área de tecnologia, com foco no desenvolvimento de aplicações web e na evolução como desenvolvedor Full Stack.

Neste portfólio estão reunidos projetos desenvolvidos durante meus estudos e experiências práticas, envolvendo desenvolvimento Front-end, Back-end, APIs REST, bancos de dados e integração com inteligência artificial.

Entre os projetos apresentados estão sistemas de gerenciamento, aplicações web, APIs e sites institucionais desenvolvidos para profissionais. Um dos projetos mais recentes é o Clinicflow, sistema Full Stack para gerenciamento de clínicas, desenvolvido com Angular, Java, Spring Boot e PostgreSQL.

O portfólio conta com layout responsivo para desktop e dispositivos móveis, apresentação profissional, área de especialidades, timeline interativa de projetos, visualização detalhada de cada aplicação e formulário de contato.
